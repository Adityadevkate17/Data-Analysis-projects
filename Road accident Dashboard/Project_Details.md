# 🚗 Road Accident Analysis Dashboard

## Project Overview
This project analyzes road accident data using Microsoft Excel and provides interactive insights into accident severity, vehicle types, road conditions, environmental factors, and casualty trends.

## Dataset Used
[Road Accident Dataset](https://github.com/Adityadevkate17/Data-Analysis-projects/blob/main/Road%20accident%20Dashboard/DataSet_accident%20data.csv.csv)

## Tools Used
- Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## KPIs
- Total Casualties
- Fatal Casualties
- Serious Casualties
- Slight Casualties
- Casualties by Cars

## Dashboard Analysis
- Vehicle Type Analysis
- Road Type Analysis
- Road Surface Condition Analysis
- Urban vs Rural Casualty Analysis
- Light Condition Analysis
- Monthly Casualty Trend Analysis
- Current Year vs Previous Year Comparison
